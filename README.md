# Виявлення смуг дорожньої розмітки класичними методами

STEM-проєкт з дисципліни «Комп'ютерна графіка та візуалізація» (КНУ, ФІТ).
Команда: **Фояк Віталій**, **Сивопляс Максим**.

Програма знаходить смуги розмітки на фото з камери автомобіля чотирма
пайплайнами класичних методів комп'ютерної графіки й порівнює їх на 100 фото
відкритого набору [CULane](https://xingangpan.github.io/projects/CULane.html).
Усі алгоритми написано вручну: без OpenCV, без ШІ та машинного навчання.

## Запуск з нуля

Потрібен Python 3.10 або новіший. Спершу перевір версію:

```bash
python3 --version
```

Якщо там 3.9 або старіший (так буває на macOS, де `python3` — системний),
встанови новий Python з [python.org](https://www.python.org/downloads/) і в
наступних командах пиши `python3.13` замість `python3` (на Windows —
`py -3.13`). Інакше тести впадуть з незрозумілою помилкою
`TypeError: unsupported operand type(s) for |`.

```bash
git clone <посилання на репозиторій>
cd lane-detection-classical
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
python -m pip install -r requirements.txt
python -m pytest
```

Фото вибірки в репозиторій не входять (ліцензія CULane). Учасники команди
отримують приватно архів `sample.zip` і розпаковують його в теку `data/`:

```bash
unzip sample.zip -d data/        # має з'явитися data/sample/normal/… тощо
```

Як зібрати вибірку самому з CULane — [docs/data.md](docs/data.md). Коли фото
лежать у `data/sample/`:

```bash
python main.py run --pipeline all     # обробка, проміжні стадії, metrics.csv
python main.py run --pipeline p3 --limit 10
python main.py report                 # summary.csv і графіки
python main.py check                  # еталонні сценарії
```

**Вікно для показу** — найпростіше, щоб побачити, як працює кожен метод:

```bash
python gui.py
```

Обираєте групу й фото, метод p1–p4, і кнопками «Назад» / «Далі» проходите кроки
методу з поясненням простими словами; праворуч — оцінка IoU, на вкладці
«Порівняння методів» — результат усіх чотирьох на тому самому фото. Параметри
можна змінити прямо у вікні («Налаштування для експериментів»), `config.json`
при цьому не змінюється.

Усі параметри методів — у [config.json](config.json). Результати — у
`results/`: для кожного фото проміжні стадії (`01_…png`), маска й фото з
лініями, а також `metrics.csv`, `summary.csv`, `c1_check.csv`, `figures/`.

## Структура

```
main.py              точка входу: run, report, check
gui.py               вікно: кроки методу, оцінки, порівняння на одному фото
config.json          усі параметри
lanes/               спільна інфраструктура: читання, ROI, маски, метрики, раннер
lanes/methods/       методи обробки, по одному файлу на метод
lanes/pipelines/     пайплайни p0–p4
tests/               автотести
tools/make_sample.py збирає вибірку з CULane
docs/                специфікації, дані, план звіту
```
