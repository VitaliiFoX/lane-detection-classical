# План звіту

Структура — з розділу «Вимоги до реалізації → Звіт» методички. Звіт один на
команду, але кожен розділ має автора: на захисті кожен відповідає за свій.

| Розділ | Зміст | Автор |
|---|---|---|
| Анотація, ключові слова | 5–7 речень: задача, методи, вибірка, головний результат з числом | разом |
| Вступ | актуальність (асистенти водія, автопілот), мета, задачі | разом |
| Огляд суміжних робіт | щонайменше 5 робіт: класичні (Хаф, вид зверху, ковзні вікна) і нейромережеві (SCNN та новіші на CULane); таблиця «підхід — дані — точність — чим відрізняється від нашого» | кожен ≥ 3 джерела, таблиця разом |
| Опис вибірки | CULane, 5 груп по 20 фото, як відбирали, приклади кадрів, ліцензія | Фояк |
| Спільна інфраструктура | схема програми, ROI, маски, метрики, базова лінія p0, автотести | обидва, кожен свою частину |
| Пайплайни p1, p2 | схема стадій, формули, параметри й чому такі (з пілоту), лістинг ключових функцій | Фояк |
| Пайплайни p3, p4 | те саме | Максим |
| Результати p1 vs p2 | фото до/після й проміжні стадії, таблиця метрик за групами, графіки, висновок «де кращий який» | Фояк |
| Результати p3 vs p4 | те саме | Максим |
| Зведене порівняння 4 пайплайнів | `summary.csv`, графіки за групами, час, таблиця C1 | разом |
| Обговорення | чому так вийшло, обмеження методів, порівняння з сучасними підходами | кожен своє + разом |
| Висновки й напрями подальшої роботи | | разом |
| Список джерел | ДСТУ 8302:2015 або APA | разом |
| Додатки | повний код, посилання на репозиторій | разом |

Числа в звіті беремо лише з реальних прогонів (`results/`), ніколи не
вигадуємо й не округлюємо на свою користь.
