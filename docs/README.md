# docs

Довгі документи. Короткі нотатки лежать поруч із кодом у `README.md` тек.

| Файл | Зміст |
|---|---|
| `pipelines.md` | специфікація 4 пайплайнів, Хафа, ROI і всіх ключів `config.json` |
| `metrics.md` | метрики, еталонні сценарії C1, пороги, формат CSV |
| `data.md` | CULane, ліцензія, як зібрати й передати вибірку |
| `report-outline.md` | розділи звіту й автори |
| `related-work.md` | огляд суміжних робіт: джерела кожного учасника й таблиця порівняння (T4) |
| `experiments.md` | журнал пілоту: які параметри пробували й чому обрали (з T1) |
| `report/zvit.md` | звіт цілком (T5, T6): розділи обох учасників і спільні; рисунки — з `results/`, титулка — `report/shablon.docx`, .docx і .pdf збирає `tools/build_report.py` |
| `defense/<прізвище>.md` | підготовка до захисту (з T7) |

`pipelines.md` і `metrics.md` — специфікації, а не опис коду. Якщо код і
документ розходяться, один із них помилковий: виріши, який, і виправ.
