# lanes/methods

Методи обробки — по одному файлу на метод. Це основна частина роботи, яку
оцінюють і про яку питають на захисті.

| Файл | Метод | Категорія | Пайплайни | Задача | Власник |
|---|---|---|---|---|---|
| `color.py` | сіре, HSV, маска білого й жовтого | колірна корекція | p1 (+ сіре для p2–p4) | F6 | Фояк |
| `histogram.py` | вирівнювання гістограми | гістограмна корекція | p2 | F9 | Фояк |
| `threshold.py` | поріг Оцу (ітеративний) | сегментація | p2 | F10 | Фояк |
| `sobel.py` | фільтр Собеля | контурний аналіз | p1, усередині Кенні | F7 | Фояк |
| `hough.py` | перетворення Хафа для прямих | перетворення Хафа | p1, p2, p4 | F8 | Фояк (спільний) |
| `perspective.py` | перспективне перетворення | геометричні перетворення | p3 | M3 | Максим |
| `prewitt.py` | фільтр Прюітта | фільтрація | p3 | M5 | Максим |
| `sliding_windows.py` | гістограма стовпців, ковзні вікна | гістограмний аналіз | p3 | M6 | Максим |
| `morphology.py` | ерозія, дилатація, відкриття, top-hat | морфологія | p4 | M4 | Максим |
| `canny.py` | метод Кенні | контурний аналіз | p4 | M7 | Максим |

Спільний примітив `apply_kernel` (ядро 3×3, 5×5) — у `lanes/filters.py`.

Взірець стилю — перший готовий метод (`filters.apply_kernel`, F1): докстрінг
із формулою, коментар до кожного кроку, тест з ручним розрахунком.
