# lanes/pipelines

Пайплайни — послідовності стадій. Кожен файл має функцію
`run(image, config) -> PipelineResult` (контракт — `base.py`,
`docs/pipelines.md`, ADR-0005) і рядок у `REGISTRY` в `__init__.py`.

| Файл | Стадії | Задача | Власник |
|---|---|---|---|
| `p0_baseline.py` | — (порожня маска, базова лінія) | готово | Фояк |
| `p1_color.py` | HSV-маска → Собель → Хаф | F12 | Фояк |
| `p2_otsu.py` | вирівнювання гістограми → Оцу → Хаф | F13 | Фояк |
| `p3_top_view.py` | вид зверху → Прюітт → ковзні вікна | M8 | Максим |
| `p4_tophat.py` | top-hat → Кенні → Хаф | M9 | Максим |
