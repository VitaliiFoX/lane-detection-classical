# tests

pytest. Запуск — `python -m pytest` з кореня.

| Файл | Що перевіряє | Власник |
|---|---|---|
| `conftest.py` | фікстура `config` | Фояк |
| `test_project.py` | каркас: конфігурація, реєстр, p0 | Фояк |
| `test_<модуль>.py` | метод або модуль з тією ж назвою | власник модуля |
| `test_p1_color.py` … `test_p4_tophat.py` | пайплайн на синтетичному кадрі | власник пайплайна |
| `test_edge_cases.py` | крайні входи для всіх пайплайнів (C2) | Максим |
